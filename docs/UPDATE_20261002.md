# Update 2026-10-02

This package consolidates the latest RumaFin changes and the voice-interpretation hardening applied after the observed account-creation misclassification.

## Included

- Google OAuth option remains removed from the login page.
- Desktop top-right `Tambah transaksi` button is replaced by `Logout`. Quick-add remains available from the sidebar and mobile add button.
- Voice Superpower remains enabled, including guarded account/ledger administration commands.
- Voice intent routing is now: Gemini 3.8 Flash → Groq GPT-OSS 120B → Groq GPT-OSS 20B → Gemini 3.5 Flash → Gemini 3.5 Flash-Lite.
- Every voice-model result is normalized and semantically validated against the original transcript before the fallback chain stops.
- Explicit `buat akun`/`buat rekening` commands cannot be accepted as `CREATE_TRANSACTION`.
- The reported transcript `Buat akun baru bernama Bank Mandiri dengan saldo 10 juta rupiah` is covered by regression tests and normalizes to `CREATE_ACCOUNT`, `BANK`, and opening balance `10000000`.
- Missing transaction account/category no longer silently becomes Cash/Others, and missing transaction amount no longer renders as Rp0.
- Preview returns `can_commit` and `blocking_issues`; both the frontend and server-side commit path refuse incomplete commands.
- Preview and commit revalidate the persisted command against its original transcript.
- AI categorization uses deterministic household rules/history first, then the configured text-model fallback. AI categorization failure does not block the manual financial workflow.
- Receipt routing and manual review behavior remain unchanged from the previous package.

See `docs/VOICE_FIX_20261002.md` for the root-cause analysis and expected result.

## Deploy changed backend functions

```bash
npx supabase functions deploy voice-interpret
npx supabase functions deploy transaction-command-preview
npx supabase functions deploy transaction-command-commit
```

No new database migration is required for this voice interpretation fix. The existing `202610020001_voice_superpower.sql` migration remains required on environments where it has not yet been applied.

Update the intent-model secrets if needed:

```bash
npx supabase secrets set GROQ_INTENT_MODEL=openai/gpt-oss-120b
npx supabase secrets set GROQ_INTENT_FALLBACK_MODEL=openai/gpt-oss-20b
```
