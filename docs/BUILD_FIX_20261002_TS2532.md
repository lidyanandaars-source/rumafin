# Build fix 2026-10-02 — VoiceDialog TS2532

Cloudflare build failed at `src/features/voice/VoiceDialog.tsx` because `noUncheckedIndexedAccess` correctly treats `matches[0]` as possibly undefined even after checking `matches.length === 1`.

The parent-category matching code now stores the array element in `parentCategory` and guards it before dereferencing `id`.

This is a type-safety/build fix only. The existing multi-command voice UI and batch interpretation flow remain enabled.
